# Qué no muestra el dashboard

El dashboard resume los resultados principales en tres pestañas. Esta parte del libro reúne el desarrollo completo del cuaderno, con los análisis y las decisiones que no caben en el dashboard. La tabla indica dónde está cada detalle.

| Diccionario de variables y estructura de los datos | {doc}`secciones 1.4 y 1.5 <01_base-de-datos>` |
| Calidad de los datos: faltantes (patrón y mecanismo), duplicados, valores imposibles y códigos especiales, atípicos, sesgos de muestreo | {doc}`sección 1.6 <01_base-de-datos>` |
| Consideraciones éticas | {doc}`sección 1.7 <01_base-de-datos>` |

| Análisis univariado y bivariado, correlaciones, multicolinealidad y selección preliminar de variables | {doc}`secciones 3.2 y 3.3 <03_analisis-exploratorio>` |
| Análisis multivariado: PCA, atípicos multivariados y estructura de grupos | {doc}`sección 3.4 <03_analisis-exploratorio>` |
| Auditoría de fuga: disponibilidad de cada variable, desempeño univariado, efecto de `duration` y duplicados entre entrenamiento y prueba | {doc}`sección 3.5 <03_analisis-exploratorio>` |
